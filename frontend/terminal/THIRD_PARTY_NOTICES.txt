THIRD-PARTY NOTICES
===================

`terminal.js` is bundled by `build.mjs` (esbuild) into a single ESM asset,
`webapp/src/main/assets/www/oc-terminal.js`, which ships inside the APK. That bundle
embeds the runtime xterm code below, so their MIT notices travel with the binary.

Only the three packages that actually run in the shipped bundle are listed. The
bundler (`esbuild`) is a devDependency used at build time only; its code is not
present in the shipped asset and it is therefore not reproduced here.

esbuild's `legalComments: "eof"` keeps only the short `@license` headers from each
file, not the license texts themselves, so the full notices are supplied below and
are also injected as a banner at the top of the built asset by `build.mjs`.
