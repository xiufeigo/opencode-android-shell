# AUDIT A4 — Settings / Command Palette / Terminal / i18n（v2 parity delta）

- 基线：`_upstream` v2 分支（`packages/app`, `packages/ui`, `packages/session-ui`）；原生：`app/src/main/java/com/xiufeigo/opencodeshell/`。
- 方法：逐文件对照 v2 源码与原生实现；i18n 用脚本规则（dotted key → 下划线资源名，大小写保留）对 `app/src/runtime/i18n/en.ts`（1373 keys）＋ `ui/src/i18n/en.ts`（242 keys）合计 1615 keys 与 `res/values/strings_oc_i18n.xml`（1082 strings）求差。**必须用并集求差**——若只用 app 源会把 191 个 `ui.*` key 误判为 stale。
- 只写本报告，不改任何源码、不跑构建。
