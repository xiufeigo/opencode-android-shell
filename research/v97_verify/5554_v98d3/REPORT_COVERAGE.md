### 3.1 定位到的三个具体机制（前两轮只报「表单不稳定」）

1. **Password 认证必须点两次 `Add server`** —— 表单点一次只把草稿交给口令弹层，
   口令弹层再点一次才落库。**这是前几轮「条目没建成」的最可能主因。**
   ```
   $ 表单已精确填好
     ET [138,1046][943,1172] text='ssh -p 2222 sshtest@127.0.0.1'
     ET [138,1246][943,1372] text='E2ECHK5554d3c-01'
     Add server [760,1383][938,1424]
   $ 点一次 Add server 之后 —— 弹出口令层，条目【尚未落库】
     'Password'  y=994 ;  'Enter the password for this connection.'  y=1294
     ET [138,1152][943,1278] ; Cancel / Add server  y=1383
   ```

2. **面板搜索框会吞文本**（复现上一轮的「串入搜索框」）：
   ```
   $ ET [180,672][901,798] text='E2ECHK5554d3c-02'
   $ 同屏 'No results found' [148,1395][415,1436]
   ```
   按 y 排序取「最下面两个 EditText」会把搜索框当表单字段。
   必须以 `Host or SSH command` 标签的 y 为锚点取其正下方第一个 EditText。

3. **IME 显隐改变整个面板几何**，视口在两值间跳：
   ```
   IME 收起: ScrollView [43,800][1038,1937]   ← 报告基线
   IME 展开: ScrollView [43,517][1038,1541]   ← 高度 1024 而非 1137
   ```
   ⇒ 任何硬编码 y 都会失效，必须每步重新 dump。

4. **PowerShell 会插值掉 shell 变量**，清理字段的 DEL 循环必须用**单引号**：
   ```
   $ "i=0; while [ $i -lt 60 ]; do input keyevent 67; i=$((i+1)); done"
   i+1:
    7 |  ... i=$((i+1)); done
      |             ~~~  'i+1' 不能被识别为 cmdlet
   ```
   修法：单引号 `'i=0; while [ $i -lt 300 ]; do input keyevent 67; i=$((i+1)); done'`。
   300 字符单次约 25–40 s，是本轮时间预算的主要消耗项。
