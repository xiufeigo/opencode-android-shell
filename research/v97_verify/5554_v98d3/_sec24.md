## 4. 未闭环 / 给下一轮

1. **【最高优先】废弃"数 `<string>` 行数"这套落库口径。** SSH 隧道表 = **单键内的列表**（`AXhs57KqmMxUXQA/...`）；正确口径 = **该键 value 长度 / 文件字节数 / 快照 MD5**。第五轮"落库 0 条"因此**不能**作为"未落库"的独立证据 —— 本轮已用"创建 +192 / 删除 −192"严格对称闭环证明这套口径可用。
2. **口令框残余缺陷**：进树了但可能**擦着裁切线**停住 ⇒ 中心点落进页脚带、点不中（§1.3 两组读数：`[138,1708][943,1788]` cy=1748 失败 vs `[138,1615][943,1741]` cy=1678 成功）。建议把验收口径从"在 a11y 树里"改成"**中心点落在表单 body 裁切面 `[43,1343][1038,1725]` 内**"。
